# Base-330 with extra steps

[Base-330](https://github.com/shaderLABS/Base-330) template pack with more stuff on top of it

- Linearized RGB
- Proper folder structure & dimension stubs
- Deferred (solid) & forward (translucent) lighting
- Uniforms in that one file right there
- Normals (colortex1, orthogonal encoding -- RG holds face normals, BA also holds face normals but is supposed to be perbuted PBR normals)
- Like a coordinate space conversion library and a hash function library

It's the structure I tend to converge on
